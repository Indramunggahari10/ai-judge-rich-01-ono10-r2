# ai-judge-rich-01-ono10-r2

One fixed money plan for make.fun's "Make the AI judge rich" bounty: the plan an AI agent with $100, a computer with internet access, and 30 days would follow, with no human doing the work. `main.py` writes the plan to `entry.txt`, byte-identical on every run.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
